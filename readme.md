# About

This is the source code for my blog.

## Info

The blog is hosted on [npatta01.github.io](https://npatta01.github.io) using github static pages.

The blog is build using [Hugo](https://gohugo.io/).

## Development

Install Hugo extended 0.165.0, then run:
```
hugo server -D
```

http://localhost:1313/

## Deployment

GitHub Actions builds the blog on pushes to `source` and publishes `public/` to `master`.
